# 手机截图拍摄指南

Play 要求：**至少 2 张、最多 8 张**手机截图。

## 规格（很容易踩坑）

| 项 | 要求 |
| --- | --- |
| 格式 | JPEG 或 24 位 PNG（**不能带透明通道**） |
| 最小边 | ≥ 320 px |
| 最大边 | ≤ 3840 px |
| ⚠️ 长宽比 | **最长边不得超过最短边的 2 倍** |
| 建议成品尺寸 | **1080 × 2160**（1:2，安全通过） |

> 现代手机截图是 1080×2400（长宽比 2.22），**直接上传会被 Play 拒绝**。
> 用下面的命令裁成 1080×2160 再传。

## 拍摄步骤

1. 先在真机上安装 **debug 包**（debug 版本关闭了 `FLAG_SECURE`，可以截图；正式包截出来是黑的）：
   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```
2. 先在应用里准备一份**演示数据**（不要用你的真实密码！），建议 6–8 条，覆盖 3 个分类：
   `GitHub / 公司邮箱 / 招商银行 / Netflix / 家里路由器 / 阿里云`

3. 逐屏截图并导出：
   ```bash
   adb exec-out screencap -p > shot1.png
   ```

4. 裁成 1080×2160（居中裁剪，会裁掉约 120px 顶部 + 120px 底部，截图时注意留白）：
   ```bash
   sips -c 2160 1080 shot1.png --out store/screenshots/01-vault-zh.png
   ```

5. 检查无透明通道：
   ```bash
   sips -g hasAlpha store/screenshots/*.png
   ```

## 建议拍摄的 5 屏

| 序号 | 页面 | 建议加的字幕（Play 会自动加设备外框，字幕可后期加也可不加） |
| --- | --- | --- |
| 01 | 首页密码列表（含分类芯片、搜索框） | 你的密码，只存在你的手机里 |
| 02 | 密码详情底部面板（密码可切换明文） | 一键查看、复制，60 秒自动清空剪贴板 |
| 03 | 密码生成器面板（强度条满格） | 内置生成器，强度一目了然 |
| 04 | 2FA 页（验证码 + 环形倒计时） | 2FA 验证码，扫码即可导入 |
| 05 | 设置页（含隐私政策、删除账号入口） | 随时导出、随时删除，数据由你掌控 |

英文列表另拍一套同样内容，文件名后缀改成 `-en`。

## 命名规范

```
store/screenshots/
├── 01-vault-zh.png
├── 02-detail-zh.png
├── 03-generator-zh.png
├── 04-2fa-zh.png
├── 05-settings-zh.png
├── 01-vault-en.png
└── ...
```

## 拍摄注意事项

- 状态栏保持干净：打开飞行模式、电量充到 90% 以上、关闭通知（否则截图里会露出微信消息）
- 系统语言：中文列表用简体系统语言拍，英文列表切英文
- 深色模式建议也拍一套（可选，能体现适配质量）
- **绝不要**在截图里出现真实姓名、真实邮箱、真实密码
