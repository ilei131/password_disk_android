# 内容分级问卷（Content rating）填写对照

Play 管理中心 → **应用内容 → 内容分级**，填写 IARC 问卷。以下是本应用的推荐答案。

## 类别选择

**工具类 / 实用工具（Utility / Productivity）** — 不要选"游戏"。

## 问卷答案

| 问题 | 答案 | 理由 |
| --- | --- | --- |
| 应用是否包含暴力内容？ | 否 | — |
| 是否包含血腥或恐怖内容？ | 否 | — |
| 是否包含性内容或裸露？ | 否 | — |
| 是否包含粗俗或侮辱性语言？ | 否 | — |
| 是否包含受管制物品（毒品、酒精、烟草）相关内容？ | 否 | — |
| 是否包含赌博内容或模拟赌博？ | 否 | — |
| 是否包含用户生成内容并对外公开？ | **否** | 密码条目仅保存在本机 / 用户自己的加密备份中，不对其他用户可见 |
| 是否允许用户互相交流？ | **否** | 无聊天、评论、社交功能 |
| 是否分享用户的位置信息？ | 否 | — |
| 是否允许用户购买数字商品？ | 否 | 无内购 |
| 是否包含广告？ | 否 | — |
| 应用是否会收集或分享用户个人信息？ | **是** | 可选的云端备份会上传用户名与加密备份，详见 `data-safety.md` |
| 是否面向儿童设计？ | **否** | 目标受众 13 岁以上 |
| 是否包含"数字购买"以外的商业推广？ | 否 | — |

## 预期评级

- **Google Play：所有人（Everyone / 3+）**
- IARC 通用评级通常为 **PEGI 3 / ESRB Everyone**

如果问卷结果出现「中等成熟度」之类的高评级，多半是某一项勾错了（最常见是误选了"用户生成内容"或"分享位置"），请回退检查。

## 目标受众设置（应用内容 → 目标受众和内容）

| 字段 | 建议值 |
| --- | --- |
| 年龄组 | **13 岁以上**（可再勾选 18+ 以规避家庭政策） |
| 是否吸引儿童 | 否 |
| 是否面向儿童销售 | 否 |

> 只要勾选了 13 岁以下任意年龄段，就必须满足 Families 政策（家庭安全标签、广告限制等），
> 密码管理类应用没有必要进入该计划，**请勿勾选 13 岁以下**。
